# Reproduce the Figure 11 correction

This branch updates the Figure 11 data selection and plotting path. It plots SWOT's residual CCT gap to Ideal in the original four-column style, grouped by reconfiguration delay. Other paper figures are not regenerated by the commands below.

## Recreate the replacement figure and table

From the repository root (Python 3.12 is pinned in `.python-version`, matching the recorded trials):

```bash
uv sync --frozen --extra notebook
MPLBACKEND=Agg uv run --frozen --extra notebook python scripts/reproduce_fig11.py
```

Outputs are `figures/paper_reproduce/exp2.2_impact_Treconf.{pdf,png,csv,json}`. The JSON records input/output hashes, plotted values and axis ranges. The input is the checked-in 84-point snapshot `data/fig11-correction/results.csv`; no solver is invoked for this path. All metric values are recalculated from the CCT columns. Missing, duplicate or mixed-parameter grids fail rather than being filled or clamped.

The original CLI Figure 11 entry and its notebook cell use this same renderer:

```bash
MPLBACKEND=Agg uv run --frozen --extra notebook python scripts/simulation_fig.py \
  --skip-exp11 --skip-exp12 --skip-exp13 --skip-exp21
```

## Rerun the experiment

```bash
MPLBACKEND=Agg uv run --frozen --extra notebook python scripts/run_fig11_matrix.py
```

This runs the complete 84-point grid sequentially with resume and heartbeat output. It writes fresh results and per-run logs below `logs/`, then generates a separate figure below `figures/fig11_rerun/`. It never overwrites the checked-in snapshot. For a one-point smoke run use `--limit 1`; run without that flag afterward to resume the remaining grid.

Parameters are fixed in `config/matrix/paper/exp2.2-matrix_sweep_msg+Tr.toml`: p=256, k=4, B=25 GB/s per plane, base latency 0.02 ms, reconfiguration delays 0.02/0.2/2/20 ms, payloads 0.125/0.5/2/8/32/128/512 decimal MB. The original trials used PuLP 3.3.0/CBC 2.10.3, eight threads, both seeds set to 1, a 120 s configured budget and a 5% target gap. Independent reruns may return different feasible incumbents because elapsed-time termination and multithreading are not bitwise deterministic. Redrawing the saved dataset reproduces the reported values exactly; PDF metadata can vary.

The rerun path preserves CBC termination, incumbent, bound, raw and adjusted times, selected schedule and physical/model validation. Invalid incumbents fail validation. Baseline fallback is explicit and recorded. The implementation includes the configuration-readiness and time-bound fixes used for the saved trials; these details do not change the plotted metric definition.
